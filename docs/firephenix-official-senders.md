# 内置发件人目录

核对日期：2026-10-16。目录只控制远程图片偏好，不触发自动翻译或总结，也不是发件人身份认证。
只匹配完整邮箱或表中明确列出的完整域名；不自动扩展子域，不匹配显示名称、Reply-To、收件人或公共邮箱域。
用户的精确邮箱禁用项优先于允许项；精确允许项可覆盖品牌默认禁用。其他未匹配地址需手动加载。
升级时所有旧自动处理和图片规则停用，四个手动名单清空；服务与加密凭据保留。

## 名单维护

唯一数据源为 [`official-senders.json`](../feature/mail/processing/internal/src/main/resources/official-senders.json)。
该文件直接打包进应用；地址不写在 Kotlin 列表中。当前共 16 个品牌，Anthropic / Claude 默认禁止图片，其他品牌默认允许。
不显示官方身份标志；名单匹配不代表邮件通过身份认证。

名单仅随应用版本更新，没有在线刷新按钮、下载请求或独立更新缓存。
维护者修改匹配项时，核对品牌官方来源、递增 `revision` 并随应用发布；`schemaVersion` 当前为 `1`。
内置目录不改变手动加入的四个名单、服务配置或加密凭据。
